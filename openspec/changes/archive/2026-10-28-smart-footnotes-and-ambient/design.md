# Технический дизайн (Design): Всплывающие сноски и Фоновый Эмбиент

## Контекст (Context)
См. `proposal.md` для общего обоснования и пользовательских сценариев.
В кодовой базе LiReader:
- Парсинг книг централизован в `lib/services/book_parser_service.dart`.
- Отрисовка текста главы выполняется в `lib/widgets/reader/chapter_content_view.dart` через `SelectableText.rich(...)`.
- Для фонового звука в проекте уже есть опыт реализации фоновых синглтонов (`TtsService`), однако специализированный звуковой плеер для непрерывных аудиодорожек пока отсутствует.

## Цели и Ограничения (Goals / Non-Goals)

**Цели:**
- Извлекать примечания и сноски в `Map<String, String> footnotes` при загрузке FB2/EPUB.
- Перехватывать клики по сноскам в тексте и показывать компактный `SmartFootnoteSheet` без перемещения по экрану.
- Создать `AmbientSoundService` на базе `just_audio` для бесшовного зацикливания дорожек в фоне без щелчков.
- Добавить стильное меню управления звуком в читалку (дорожки, громкость, таймер).

**Ограничения (Non-Goals):**
- Загрузка сторонних аудиофайлов из файловой системы устройства (в первой версии используются встроенные оптимизированные ассеты).
- Онлайн-стриминг аудио (приложение остается строго автономным).

## Технические решения (Decisions)

### 1. Выбор аудиоплеера: `just_audio` вместо `audioplayers`
- **Решение**: Использовать `just_audio: ^0.9.43`.
- **Обоснование**: `just_audio` обеспечивает гарантированно бесшовный переход в цикле (`LoopMode.one`) на Android через ExoPlayer, имеет низкое потребление батареи и не конфликтует с параллельным синтезом речи `flutter_tts`.
- **Альтернативы**: `audioplayers` (в прошлом имел микропаузы и щелчки на стыке лупа), ручной Web Audio/Platform Channel.

### 2. Хранение сносок в `BookParsedData`
- **Решение**: Добавить поле `Map<String, String> footnotes` в модель `BookParsedData`. Ключом является нормализованный `id` ссылки (например, `n_1`, `note-1`), значением — очищенный текст примечания.
- **Обоснование**: Мгновенный O(1) поиск сноски по ключу при клике в UI без повторного сканирования диска или XML-дерева.

### 3. Интерактивные сноски в `ChapterContentView`
- **Решение**: При формировании `TextSpan` выявлять сносочные теги/ссылки и оборачивать их в кликабельный `TextSpan` с `TapGestureRecognizer` и специальным визуальным выделением (акцентный цвет, надстрочный стиль).
- **Обоснование**: Пользователь видит сноску как интерактивную кнопку-ссылку прямо в строке текста.

### 4. Архитектура `AmbientSoundService`
- **Решение**: Создать синглтон `AmbientSoundService.instance` с `ValueNotifier` для реактивного обновления UI:
  - `isPlayingNotifier`
  - `currentTrackNotifier`
  - `volumeNotifier`
  - Метод `play(AmbientTrack track)`, `pause()`, `setVolume(double)`, `fadeStop(Duration duration)`.

## Риски и Компромиссы (Risks / Trade-offs)

- **[Риск] Размер APK из-за звуковых файлов**  
  → *Митигация*: Использовать высокосжатые файлы OGG/MP3 (битрейт 64-96 kbps, моно/легкое стерео). Для 4 треков по 45 секунд размер составит не более 2-3 МБ.
- **[Риск] Конфликт звука с системным TTS**  
  → *Митигация*: Настроить аудиофокус `AudioSession` в режим `duckOthers` или параллельного микширования, чтобы эмбиент мягко приглушался во время чтения вслух.
- **[Риск] Сложные HTML-структуры сносок в редких EPUB**  
  → *Митигация*: Если по id сноска не найдена в словаре, мягко открывать поиск или стандартный переводчик без падения приложения.
